# نظام الإدارة المالية الشخصية — Personal Finance Manager

تطبيق ويب عربي (RTL) لإدارة الأهداف المالية الشخصية: خطط **ادخار** و**سداد ديون** و**استثمار**، مع لوحة تحكم تحليلية وسجل دفعات تفصيلي لكل خطة.

Arabic-first personal finance web app — savings, debt payoff and investment plans with an analytics dashboard. Built with ASP.NET Core MVC and PostgreSQL.

> نسخة عرض (Portfolio): يحتوي المشروع على حساب تجريبي ببيانات **وهمية** يُنشأ تلقائياً عند التشغيل.

---

## المزايا

| القسم | ماذا يقدم |
|---|---|
| **لوحة التحكم** | إجمالي الأهداف، المبالغ المحققة، المتبقي، ونسبة الإنجاز العامة |
| **الرسوم البيانية** | تقدّم الخطط شهرياً (أعمدة / منطقة) لآخر 12 شهراً، ودائرة توزيع المنجز والمتبقي لكل خطة |
| **الخطط المالية** | عدد غير محدود من الخطط بثلاثة أنواع: ادخار، سداد دين، استثمار — لكل خطة لون وهدف وتاريخ بداية ونهاية |
| **خريطة الدفعات** | شبكة مربعات لعدد الدفعات المخطط لها، تُضاء تلقائياً مع كل دفعة مسجّلة، ومبلغ قسط ثابت أو محسوب تلقائياً |
| **سجل الدفعات** | إضافة وتعديل وحذف الدفعات بالتواريخ والملاحظات، ومتوسط الدفعة |
| **أنواع الدفع** | سداد فاتورة، سداد سلفة، أو **مبلغ محجوز** للمستقبل لا يُخصم حتى يُحوَّل لسداد فعلي بضغطة |
| **إيقاف مؤقت** | إيقاف خطة مؤقتاً فتُستبعد من إجماليات ورسوم لوحة التحكم حتى إعادة تفعيلها |
| **الحسابات** | تسجيل دخول وإنشاء حساب (ASP.NET Identity) مع رسائل أخطاء عربية، وكل مستخدم يرى خططه فقط |
| **التخصيص** | وضع ليلي / نهاري، اختيار الخط (IBM Plex Sans Arabic، Cairo، Tajawal)، وقائمة جانبية قابلة للطي |

## التقنيات

- ASP.NET Core MVC (.NET 10) · C#
- Entity Framework Core + PostgreSQL (Npgsql)
- ASP.NET Core Identity
- Tailwind CSS (Tailwind CLI) · Razor Views
- تصميم متجاوب RTL مع دعم الوضع الليلي

## التشغيل

المتطلبات: .NET 10 SDK و PostgreSQL.

1. أنشئ ملف `appsettings.Local.json` بجانب `appsettings.json` (لا يُرفع على GitHub):
   ```json
   { "ConnectionStrings": { "DefaultConnection": "Host=localhost;Port=5432;Database=PersonalFinanceDemoDb;Username=postgres;Password=YOUR_PASSWORD" } }
   ```
2. شغّل المشروع — يُنشئ قاعدة البيانات والجداول والحساب التجريبي تلقائياً:
   ```bash
   dotnet run
   ```
3. لإعادة ضبط بيانات الحساب التجريبي في أي وقت:
   ```bash
   dotnet run -- seed
   ```
4. (اختياري) لإعادة بناء ملف التنسيق بعد تعديل الواجهات:
   ```bash
   npm install
   npm run build:css
   ```

## حساب تجريبي

| البريد | كلمة المرور |
|---|---|
| `demo@finance.local` | `Demo1234` |

يحتوي على 6 خطط جاهزة: صندوق الطوارئ، قرض السيارة، بطاقة الائتمان، محفظة استثمارية، رحلة الصيف، والدفعة الأولى لشقة (موقوفة مؤقتاً) — مع سجل دفعات لعدة أشهر.
وفي صفحة الدخول زر **"تعبئة بيانات الحساب التجريبي"** للدخول بضغطة.

أي حساب جديد يُنشأ من صفحة التسجيل يحصل أيضاً على خطتين تجريبيتين حتى لا تظهر اللوحة فارغة.

## هيكل المشروع

```

Data/          ApplicationDbContext + DemoAccountSeeder (البيانات التجريبية)

Services/      حسابات النسب والرسوم البيانية، ورسائل Identity العربية
ViewModels/    نماذج العرض
Views/         واجهات Razor عربية RTL
```
